## 🌟 معرفی پروژه

این پروژه به‌عنوان یک **نمونه‌کار مهندسی‌شده (Engineered Portfolio)** توسعه یافته است تا علاوه بر نمایش مهارت‌های طراحی رابط کاربری (UI/UX)، اصول بنیادین مهندسی نرم‌افزار شامل **ساختار معنایی (Semantic HTML)**، **تفکیک دغدغه‌ها (Separation of Concerns)**، **مدیریت وضعیت (State Management)** و **رعایت استانداردهای دسترس‌پذیری** را نیز به نمایش بگذارد.

فلسفه بصری این پروژه بر پایه استعاره **«کتابخانه فیزیکی»** بنا شده است؛ جایی که رنگ‌های کاهی، چوبی و طلایی، حس گرما و اصالت مطالعه را به کاربر منتقل می‌کنند.

> 📖 برای مطالعه کامل مستندات بصری، پالت رنگی و توکن‌های طراحی، به فایل [`DESIGN_SYSTEM.md`](./DESIGN_SYSTEM.md) مراجعه فرمایید.

## ✨ ویژگی‌های کلیدی

### 🎨 طراحی و تجربه کاربری (UI/UX)

- **چیدمان کاملاً راست‌چین (RTL):** سازگار با استانداردهای نگارشی زبان فارسی و ارقام بومی.
- **طراحی واکنش‌گرا (Mobile-First Responsive):** بهینه‌سازی‌شده برای تمامی دستگاه‌ها از عرض ۳۲۰ تا ۲۵۶۰ پیکسل.
- **تایپوگرافی حرفه‌ای:** استفاده از فونت متغیر (Variable Font) **وزیرمتن (Vazirmatn)** با ۹ وزن مختلف.
- **حالت تاریک/روشن (Theme Switching):** با ذخیره‌سازی اولویت کاربر در `localStorage` و تشخیص خودکار تنظیمات سیستم (`prefers-color-scheme`).
- **انیمیشن‌های مبتنی بر اسکرول:** استفاده از `IntersectionObserver` برای انیمیشن‌های نرم ورود سکشن‌ها.
- **افکت ماشین تحریر (Typewriter):** پیاده‌سازی‌شده به‌صورت بومی با JavaScript و رعایت `prefers-reduced-motion`.
- **نوار پیشرفت مطالعه (Reading Progress):** نمایش میزان پیشرفت کاربر در صفحه با استفاده از `transform: scaleX()` (بدون تحمیل Layout Thrashing).
- **آکاردئون پرسش‌های متداول (FAQ):** پیاده‌سازی با انیمیشن ارتفاع (Height Transition) و استفاده از تگ معنایی `<details>`.

### ♿ دسترس‌پذیری (Accessibility)

- رعایت اصول **WCAG 2.1 Level AA** در سراسر پروژه.
- استفاده صحیح از **ARIA Roles** (`banner`, `navigation`, `progressbar`, `contentinfo`).
- پیاده‌سازی **Skip Link** برای کاربران صفحه‌خوان (Screen Reader).
- پشتیبانی کامل از **ناوبری با صفحه‌کلید** (Keyboard Navigation) و مدیریت Focus.
- رعایت تنظیمات سیستم‌عامل کاربر برای **کاهش انیمیشن** (`prefers-reduced-motion`).

### ⚡ عملکرد (Performance)

- **بارگذاری تنبل (Lazy Loading):** برای تصاویر غیر بحرانی.
- **بارگذاری فوری (Eager Loading):** برای تصویر Hero جهت بهبود شاخص LCP.
- **استفاده از `requestAnimationFrame`:** برای جلوگیری از Layout Thrashing در رویدادهای اسکرول.
- **Debounce کردن رویداد Resize:** برای کاهش بار پردازشی هنگام تغییر ابعاد پنجره.
- **مدیریت رویدادها با `passive: true`:** برای بهبود روانی اسکرول.

## 🎨 سیستم طراحی (Design System)

پروژه «خوانش گستر» دارای یک **سیستم طراحی مستقل و مستند** است که از طریق **متغیرهای CSS (Custom Properties)** پیاده‌سازی شده است. این معماری، تغییر هویت بصری پروژه را از طریق ویرایش یک فایل واحد ممکن می‌سازد.

| مؤلفه                  | توضیح                                                      |
| ---------------------- | ---------------------------------------------------------- |
| **پالت رنگی**          | الهام‌گرفته از کاغذهای کاهی، چوب جنگلی و جلدهای طلایی کتاب |
| **تم‌ها**              | دو تم کامل (روشن و تاریک) با بیش از ۴۰ توکن رنگی           |
| **تایپوگرافی**         | مقیاس مبتنی بر نسبت ۱.۲۵ (Major Third)                     |
| **فاصله‌گذاری**        | شبکه ۴ پیکسلی (4px Grid System)                            |
| **شکست‌های واکنش‌گرا** | ۷ بریکپوینت استاندارد (۴۸۰px تا ۱۶۰۰px)                    |

📄 **مستند کامل:** [`DESIGN_SYSTEM.md`](./DESIGN_SYSTEM.md)

## 🏗️ معماری و تصمیمات فنی

### ۱. الگوی ماژولار IIFE

تمامی کدهای JavaScript در یک **Immediately Invoked Function Expression** قرار گرفته‌اند تا از آلودگی Scope سراسری (Global Scope Pollution) جلوگیری شده و تداخل متغیرها با کتابخانه‌های احتمالی دیگر از بین برود.

```javascript
(function () {
  "use strict";
  // کد ماژولار و ایزوله
})();
```

### ۲. استراتژی Mobile-First

تمامی استایل‌های پایه برای **کوچک‌ترین عرض صفحه** نوشته شده‌اند و در بریکپوینت‌های بالاتر، ویژگی‌های جدید **اضافه** می‌شوند. این رویکرد باعث کاهش حجم CSS و بهبود عملکرد در دستگاه‌های کم‌توان می‌گردد.

### ۳. استفاده از عناصر بومی HTML5

برای پیاده‌سازی آکاردئون FAQ از تگ معنایی `<details>` و `<summary>` استفاده شده است که **بدون نیاز به JavaScript** کار می‌کند. JavaScript صرفاً برای افزودن انیمیشن ارتفاع به این عناصر بومی افزوده شده است (Progressive Enhancement).

### ۴. افکت شیشه‌ای (Glassmorphism)

استفاده گسترده از `backdrop-filter: blur()` برای ایجاد عمق بصری و حس مدرن در کارت‌ها، هدر و عناصر شناور.

### ۵. مدیریت ایمن LocalStorage

به دلیل احتمال بروز خطا در حالت‌های خاص مرورگر (مانند Incognito یا پر بودن حافظه)، تمامی عملیات خواندن و نوشتن در `localStorage` در یک شیء کمکی به نام `safeStorage` با ساختار `try/catch` پیاده‌سازی شده است.

## 👨‍💻 راهنمای توسعه‌دهندگان

### افزودن یک سکشن جدید

۱. **تعریف HTML** در فایل `index.html`:

```html
<!-- ==========================================================
     🆕 سکشن جدید: [نام سکشن]
     ========================================================== -->
<section class="new_section reveal" id="New_Section">
  <!-- محتوای سکشن -->
</section>
```

۲. **افزودن لینک ناوبری** در `<nav id="mainNav">`:

```html
<li><a href="#New_Section" class="nav_link">عنوان سکشن</a></li>
```

۳. **نوشتن استایل** در `CSS/Style.css` با استفاده از Design Tokens:

```css
/* ========================================================================
   🆕 New Section (سکشن جدید)
   ======================================================================== */
.new_section {
  /* استایل‌های سکشن */
}
```

> ✨ **نکته:** با افزودن کلاس `reveal`، انیمیشن ورود به صورت خودکار توسط `IntersectionObserver` در `Script.js` مدیریت می‌شود.

### افزودن یک پرسش جدید به FAQ

کافی است یک بلوک `<details>` جدید درون `.faq_container` اضافه کنید:

```html
<details class="faq_item">
  <summary class="faq_question">
    <span>پرسش جدید شما؟</span>
    <span class="faq-icon"></span>
  </summary>
  <div class="faq_answer_wrap">
    <div class="faq_answer">پاسخ پرسش در این بخش قرار می‌گیرد.</div>
  </div>
</details>
```

> 🔧 انیمیشن باز/بسته شدن به صورت خودکار توسط تابع‌های `animateOpen` و `animateClose` در `Script.js` مدیریت می‌شود.

### افزودن تم جدید (مثلاً تم Sepia)

۱. بلوک متغیرهای جدید را به `CSS/Style.css` اضافه کنید:

```css
[data-theme="sepia"] {
  --bg-primary: #f4ecd8;
  --text-primary: #5b4636;
  /* ... سایر متغیرها */
}
```

۲. تابع `loadTheme` در `JS/Script.js` را به‌روزرسانی کنید تا مقدار جدید را نیز بپذیرد.

## ♿ استانداردهای دسترس‌پذیری (A11y)

این پروژه بر اساس اصول **WCAG 2.1 Level AA** طراحی شده است. مهم‌ترین ویژگی‌های دسترس‌پذیری عبارت‌اند از:

| ویژگی                   | پیاده‌سازی                                                                     |
| ----------------------- | ------------------------------------------------------------------------------ |
| **Skip Link**           | امکان پرش مستقیم به محتوای اصلی برای کاربران صفحه‌خوان                         |
| **ARIA Labels**         | برچسب‌گذاری کامل برای عناصر تعاملی و آیکون‌ها                                  |
| **Semantic HTML**       | استفاده از `<header>`, `<main>`, `<section>`, `<nav>`, `<footer>`, `<details>` |
| **Focus Visible**       | حلقه فوکوس واضح برای تمامی عناصر تعاملی                                        |
| **Color Contrast**      | رعایت حداقل نسبت کنتراست ۴.۵:۱ برای متون بدنه                                  |
| **Reduced Motion**      | غیرفعال‌سازی خودکار انیمیشن‌ها با `prefers-reduced-motion`                     |
| **Keyboard Navigation** | پشتیبانی کامل از کلیدهای Tab، Enter، Space و Escape                            |

## ⚡ بهینه‌سازی عملکرد (Performance)

### تکنیک‌های به‌کاررفته

| تکنیک                   | محل پیاده‌سازی           | توضیح                             |
| ----------------------- | ------------------------ | --------------------------------- |
| `transform: scaleX()`   | نوار پیشرفت              | جلوگیری از Trigger شدن Layout     |
| `requestAnimationFrame` | رویداد اسکرول            | هماهنگی با نرخ تازه‌سازی صفحه     |
| `passive: true`         | Event Listenerهای اسکرول | عدم مسدود شدن نخ اصلی مرورگر      |
| `Debounce`              | رویداد Resize            | کاهش فراخوانی توابع (۱۲۰ms)       |
| `IntersectionObserver`  | انیمیشن‌های Reveal       | جایگزین کارآمد برای رویداد اسکرول |
| `preconnect`            | Google Fonts             | کاهش تأخیر DNS و TLS              |
| `loading="eager"`       | تصویر Hero               | بهبود شاخص LCP                    |
